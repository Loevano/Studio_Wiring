# Instructions

This folder groups all documentation for Studio Wiring.

## Documents
- `USER_MANUAL.md`: End-user setup and day-to-day workflow.
- `PROJECT_STRUCTURE.md`: Recommended project/save layout and naming conventions.
- `documentation/TAB_ARCHITECTURE.md`: Shell + versioned tab loading layout.
- `../DATA_FLOW.md`: Canonical technical data-flow contract.
- `../VISUAL_RULES.md`: Visual routing/rendering rules.
- `../README_STUDIO_CABLING.md`: Quick start and command examples.

## Rule
When data flow, save paths, or generator I/O changes, update `../DATA_FLOW.md` in the same change.
