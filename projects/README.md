# Projects

Each project contains:
- `device-configurations/` for studio/device model JSON.
- `patch-configurations/` for one or more patch/connection JSONs.
- `outputs/html`, `outputs/svgs`, and `outputs/debug` for generated artifacts.

Global routing/label policy lives in:
- `json/routing_rules.json`

Start from `projects/_template/` when creating a new studio project.
